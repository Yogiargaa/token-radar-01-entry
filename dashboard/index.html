How the ranking is built

The board is a program's answer, not a hand-kept list. One scoring function runs over every protocol in the snapshot; no name is ever special-cased. The inputs are only the snapshot's own figures: TVL, seven-day change, listing date and chains.

Who is ranked

A protocol is ranked when its record shows no token — market cap, CoinGecko id and symbol all null — and it is not a wrapped, staked or bridged product of a token that already trades. That means its category is not a bridge, liquid staking/restaking or exchange bucket, its name carries no whole word wrapped, staked or staking, does not start with an exchange's name, and does not end in a version marker. Every protocol on the snapshot's watchlist is ranked, and so is every other eligible protocol below the watchlist floor: the floor is where the reading starts, not where it stops.

The value model

implied value = TVL × 0.30 × growth × age × reach

  • Growth = 1 + 0.40 × seven-day change, clamped to −50% … +200%. Momentum counts, but one hot week cannot dominate the board. An unreported change counts as flat.
  • Age = 0.55 + 0.45 × days listed (capped at 3 years) / 3 years. Survival counts: a protocol that ran for years with no token has a deeper base of users to reward. An unreported listing date counts as one year.
  • Reach = 1 + 0.04 per chain beyond the first, up to five extra chains. Distribution breadth counts a little.

Each protocol's detail view shows its own four factors and the arithmetic, so any rank can be checked by hand from the snapshot.

Farm plans

Every row carries six steps generated from the protocol's own record: its category picks the action, its TVL sizes the capital, its age sets the holding window, its chains name the venue. Each step states what it costs and how long it takes. Nothing here promises a token, an airdrop or a reward: a protocol that records no token may still have one its record does not carry, and a real claim never asks you to pay first.

What the board is not

The implied value is this entry's own claim, never one the data source makes. The snapshot is frozen: it does not move, and neither does this board. Figures are the snapshot's, truncated to whole dollars as recorded.
